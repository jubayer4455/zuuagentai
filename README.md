# বাপের রাস্তা · Baper Rasta (Full Replica)

> **"আপনার সন্তানকে টেসলা দিন: নো লাইসেন্স, নো ব্রেক।"**  
> ঢাকার রাজপথের বাস্তবসম্মত ব্যাটারি অটোরিকশা সিমুলেশন গেম। ধাক্কা মারেন, জাতীয় ক্ষতি বাড়ান, আর পাবলিক ধরার আগে পালান!

`https://baperrasta.com/` সাইটের সম্পূর্ণ গেমটি হুবহু (same to same) কোনো কিছু মিস না দিয়ে নিখুঁতভাবে তৈরি করা হয়েছে।

---

## 🌟 যা যা অন্তর্ভুক্ত রয়েছে (Everything Included)

1. **ফুল থ্রি-ডি গেমপ্লে ইঞ্জিন (Three.js & WebGL Procedural 3D World):**
   - ঢাকা শহরের বাস্তব রাস্তা, ডিভাইডার, ট্রাফিক জ্যাম, প্রাইভেট কার, বাস, পথচারী, হকার ও বিলবোর্ড।
   - মসৃণ ব্যাটারি অটোরিকশা কন্ট্রোল ও ফিজিক্স।

2. **সম্পূর্ণ বাংলা মিম ও অডিও সাউন্ড ইফেক্টস (`clips/*.mp3`):**
   - "মাসুদ তুমি ভালো হয়ে যাও" (`clips/masud.*.mp3`)
   - "রাগ করলা?" (`clips/rag-korla.*.mp3`)
   - "টেকনোলজিয়া" (`clips/technologia.*.mp3`)
   - "ইয়োওও" (`clips/yooo.*.mp3`)
   - ৪ ধরনের সাউন্ড বোম (`clips/sound-bomb-1` থেকে `4`)
   - পাবলিকের ধাওয়া ও চিৎকার (`clips/mob-shout-1`, `2`, `3`)
   - পাঞ্চ, কার্টুন ইমপ্যাক্ট, ক্র্যাশ ও প্যাঁ-প্যাঁ হর্ন।

3. **আসল বাংলা ফন্টসমূহ (`fonts/*.woff2`):**
   - Anek Bangla, Baloo Da 2, Galada, Hind Siliguri, Tiro Bangla, Share Tech Mono।

4. **"মোস্ট ওয়ান্টেড" লিডারবোর্ড ও ব্যাকএন্ড API (`server.js`):**
   - `GET /api/board` - সাপ্তাহিক ও সর্বকালের সেরা ক্ষতিকারকদের তালিকা।
   - `POST /api/run` - রান ট্র্যাকিং ও অথেনটিকেশন টোকেন।
   - `POST /api/score` - স্কোর সাবমিশন ও র‍্যাংক ক্যালকুলেশন।
   - `POST /api/name` - পোস্টারে প্লেয়ারের নাম এন্ট্রি।
   - `POST /api/subscribe` - ইমেইল সাবস্ক্রিপশন।
   - লোকাল ডাটাবেস পারসিস্টেন্স (`data/leaderboard.json`)।

5. **মোবাইল ও ডেক্সটপ ফুল সাপোর্ট + PWA:**
   - টাচ স্ক্রিন অন-স্ক্রিন বাটন ও ডেক্সটপ কীবোর্ড সাপোর্ট।
   - অফলাইন সার্ভিস ওয়ার্কার (`sw.js`) ও ওয়েব ম্যানিফেস্ট (`manifest.webmanifest`)।
   - সব লিগ্যাল ও তথ্যমূলক পেজ (`about.html`, `privacy.html`, `disclaimer.html`)।

## 🚀 গেমটি চালু করার নিয়ম (How to Run)

প্রজেক্ট ফোল্ডারে টার্মিনাল বা কমান্ড প্রম্পট খুলে চালান:

```bash
# সার্ভার চালু করতে:
npm start
# অথবা:
node server.js
```

এরপর যেকোনো ব্রাউজারে প্রবেশ করুন:
👉 **`http://localhost:3000`**

## 🎮 কন্ট্রোল গাইড (Controls)

| অ্যাকশন | কীবোর্ড কি |
| :--- | :--- |
| **ডানে / বামে যাওয়া** | বাম/ডান অ্যারো (`←` / `→`) অথবা `A` / `D` |
| **অ্যাক্সিলারেট (গতি বাড়ানো)** | ওপরের অ্যারো (`↑`) অথবা `W` |
| **ব্রেক / স্লো** | নিচের অ্যারো (`↓`) অথবা `S` |
| **হর্ন বাজানো** | `H` অথবা স্পেসবার (`Space`) |
| **মোবাইল কন্ট্রোল** | স্ক্রিনের টাচ বাটন |
